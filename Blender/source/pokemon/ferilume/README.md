# Ferilume generator

Run `generator.py` from its saved repository location in Blender's Text Editor. The script bootstraps `_core` from its own saved Text datablock path, loads `Blender/config/project.json`, and exports through the configured `animated_mesh` profile.

Species ID: `pokemon.ferilume`. Category: `BaseSpecies`. The destination remains under `Models/Pokemon/_ART_TEST/` until the animated FBX round-trip profile is explicitly validated in project config. Nacoryn is intentionally legless.
